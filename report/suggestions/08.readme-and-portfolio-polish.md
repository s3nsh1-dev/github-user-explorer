## What to write

````markdown
# GitHub User Explorer

Search any GitHub user or organization and explore their profile, repositories,
and contribution history — built with React 19, TypeScript, and TanStack Query.

**[→ Live demo](https://your-deployed-url.app)**

![Home page](docs/screenshots/home.png)

## Features

- **User & organization search** with infinite scroll (IntersectionObserver + `useInfiniteQuery`)
- **Contribution calendar** rendered from GitHub's GraphQL API — the same 52×7 grid GitHub shows
- **Automatic account-type detection** — organizations get a top-repositories view instead of a contribution graph
- **Paginated repository browser** with a per-repository detail page
- **Starred profiles** persisted to `localStorage` and reachable from the home page
- **Light / dark theme** with a custom animated MUI switch, persisted across sessions
- **Mobile-first responsive layout** throughout

## Tech stack

| Layer | Choice | Why |
|---|---|---|
| UI | React 19 + TypeScript | — |
| Data | TanStack Query v5 | Caching, deduplication, and infinite pagination without hand-rolled state |
| Styling | MUI v7 + Emotion | Themeable design system, light/dark out of the box |
| Routing | React Router v7 | — |
| Build | Vite 6 + SWC | — |
| API | GitHub REST v3 + GraphQL v4 | REST for profiles/repos; GraphQL for the contribution calendar, which REST doesn't expose |

## Architecture

    client/          React SPA
      src/hooks/     One hook per GitHub endpoint, all through TanStack Query
      src/context/   Theme mode + starred users
      src/page/      Route-level components
      src/helper/    API response → view model mapping
````

## Details worth getting right

- **The live demo link is the most important line.** It is currently nowhere in
  the repo.
- **Screenshots must be committed to the repo**, not hotlinked to
  `github.com/user-attachments/…`. Those URLs are tied to an upload session and
  are not a stable CDN contract; if it ever breaks, your README renders as a
  broken image icon.
- **Show the contribution chart in a screenshot.** It is the most distinctive
  thing the app does and the only feature that needed GraphQL.
- **Link to this report.** A `report/` folder that honestly catalogues your own
  project's weaknesses reads as engineering maturity — provided the critical
  items are marked fixed. Publishing a list of open critical vulnerabilities on
  a live site does the opposite. **Fix
  [`../vulnerabilities/01.exposed-github-token.md`](../vulnerabilities/01.exposed-github-token.md)
  before linking this folder publicly.**
- **Badges, sparingly.** Build status and license are useful; a wall of shields
  is not.
- **Add a `LICENSE`.** `server/package.json` claims ISC; there is no license
  file at the root. Pick MIT and commit it.
- **Add repository topics and an "About" description on GitHub** — `react`,
  `typescript`, `tanstack-query`, `github-api`, `mui`. Free discoverability, and
  the About blurb is what shows in search results.
- **The `guide.txt` at the root is your private scratchpad** ("can not
  concentrate. gotta sleep" is a real commit message in this history). Endearing,
  but it is the second file a visitor sees. Move it to `docs/` or delete it.

## Contradictions & trade-offs

- **Screenshots vs. bundle weight** — the four mockups in `extra/` are 1.4 MB
  each. Compress to ~150 kB WebP before committing them under `docs/`. See
  [07.asset-and-bundle-weight.md](07.asset-and-bundle-weight.md).
- **Linking `report/` publicly is a judgement call.** It is a strong signal
  *after* the critical items are closed, and a liability before. Gate on
  vulnerability 01.
- **Claiming a feature the deploy does not have is worse than omitting it.**
  If you go token-free
  ([`../vulnerabilities/01`](../vulnerabilities/01.exposed-github-token.md),
  Option A), the contribution calendar disappears — do not leave it in the
  feature list or the screenshots.
- **A "What I'd do differently" section can undersell the work** if it reads as
  apology. Frame it as trade-offs with reasoning, not as a list of regrets.
