## Why

[`App.tsx`](../../client/src/App.tsx) imports all five pages statically, so a
visitor who only sees the home screen still downloads the repo-detail page, the
explorer, and the contribution chart. `@mui/icons-material` is imported
piecewise across nine files and rides along.

Depends on **P12** (a lazy chunk that fails to load throws — the boundary must
exist first) and **P16** (route structure settles there; splitting first would
mean redoing it).

## Steps

### 1. Lazy-load the non-home routes

```tsx
import { lazy, Suspense } from "react";

const Explorer         = lazy(() => import("./page/Explorer"));
const LinkWrapper      = lazy(() => import("./page/LinkWrapper"));
const ShowSelectedRepo = lazy(() => import("./page/ShowSelectedRepo"));
const NotFound         = lazy(() => import("./page/NotFound"));
```

Keep `Home` **static** — it is the landing route, and lazy-loading it just adds
a round trip before first paint.

### 2. Wrap in `Suspense` inside the `<main>` landmark from P22

```tsx
<Box component="main">
  <Suspense fallback={<PageSkeleton />}>
    <Routes>…</Routes>
  </Suspense>
</Box>
```

Use a skeleton, not a spinner — consistent with **P14**/**P16**.

### 3. Confirm the chunk split actually happened

`npm run build` and read the output. Expect separate chunks for Explorer,
LinkWrapper (which pulls in ProfileInfo + Repositories + ContributionChart), and
ShowSelectedRepo. **If everything still lands in one chunk, the lazy import is
being defeated** — usually by a static import of the same module elsewhere.
Grep for stray static imports of the lazy pages.

### 4. Optional: prefetch on hover

`UserCards` links to `/user/:login`. Triggering `import("./page/LinkWrapper")`
on hover makes the transition feel instant. Only add this if the chunk split is
confirmed working — otherwise it is a no-op that looks like an optimisation.

## Acceptance criteria

- [ ] `npm run build` output shows ≥3 route chunks, not one bundle
- [ ] Initial JS transferred on `/` is smaller than the **P00** baseline; number recorded
- [ ] Navigating to each route loads its chunk (visible in the Network tab)
- [ ] No flash of unstyled/empty content between chunks
- [ ] Direct deep link to `/user/torvalds` still works (dev server; production needs the blocked host rewrite **B3**)
- [ ] Verification gate green

## Do NOT

- Do not lazy-load `Home`, `Navbar`, or the context providers. They are needed on first paint.
- Do not add `manualChunks` config. Vite's defaults are fine at this size; hand-tuning chunk strategy is premature.
- Do not lazy-load individual components (`ContributionChart` etc.). Route granularity is the right level here.
- Do not treat a green build as proof — read the chunk list. Splitting silently failing to split is the normal failure mode.
