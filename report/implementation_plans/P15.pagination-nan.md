## Why — confirmed bug

[`Repositories.tsx:11`](../../client/src/page/Repositories.tsx#L11) passes
`fullRepoCall.data?.public_repos` (`number | undefined`) into a prop declared
`totalRepos: number`. TypeScript missed it because untyped `useQuery` made
`data` `any` — **P09** fixes the blindness, this plan fixes the bug.

Runtime effect in [`Pagination.tsx:15`](../../client/src/components/Pagination.tsx#L15):

```ts
const totalPages = Math.ceil(totalRepos / 8);   // → NaN
```

`NaN <= 3` is false **and** `NaN > 3` is false → both branches skipped →
`renderNumericButtons` stays `undefined` → no page numbers render. The "last
page" button links to `?page=NaN`, and `disabled={page === totalPages}` is
always false because `NaN !== NaN`.

## Steps

### 1. Extract the page-window logic to a pure, testable function

`client/src/helper/paginate.ts`:

```ts
export const PER_PAGE = 8;

export const totalPageCount = (totalRepos: number): number =>
  Number.isFinite(totalRepos) && totalRepos > 0 ? Math.ceil(totalRepos / PER_PAGE) : 0;

/** The (up to 3) page numbers to show around `page`. */
export const pageWindow = (page: number, totalPages: number): number[] => {
  if (!Number.isFinite(totalPages) || totalPages < 1) return [];
  if (totalPages <= 3) return Array.from({ length: totalPages }, (_, i) => i + 1);
  const start = Math.min(Math.max(page, 1), totalPages - 2);
  return [start, start + 1, start + 2];
};
```

Note `PER_PAGE` is currently a magic `8` in **two** places —
`useFetchReposPerPage.ts` (`const perPage = 8`) and `Pagination.tsx`
(`/ 8`). If they ever diverge, pagination silently breaks. One constant, both
call sites.

### 2. Handle the loading state honestly in `Repositories.tsx`

```tsx
const { data, isLoading, error, refetch } = useFetchUserData({ username });
if (isLoading) return <RepoListSkeleton />;
if (error) return <ErrorState error={error} onRetry={refetch} />;
const totalRepos = data?.public_repos ?? 0;
```

Don't paper over `undefined` with `?? 0` alone — an explicit loading branch is
what stops `NaN` existing in the first place.

### 3. Rewrite `Pagination.tsx` to consume the helpers

Replace the duplicated `if (totalPages <= 3)` / `if (totalPages > 3)` blocks
with one `pageWindow(page, totalPages).map(...)`. Guard the arrows:
`disabled={page >= totalPages || totalPages === 0}`.

### 4. Render nothing when there is nothing to page

`totalPages <= 1` → return `null`. A pagination bar for a user with 3 repos is
noise.
