## Why

`client/node_modules` is not installed. I cannot verify a single change until it
is. I also need to know whether the build is green *before* I touch anything —
otherwise the first failure gets misattributed to my change.

## Steps

1. `cd client && npm ci`
   - If `npm ci` fails on lockfile drift, use `npm install` and **note that the lockfile changed** — that becomes its own commit, not a silent side effect.
2. Record the baseline, all three commands, capture exact output:
   ```bash
   npm run lint
   npx tsc -b --noEmit
   npm run build
   ```
3. Write results to `report/implementation_plans/_baseline.txt` (gitignored or committed, decide at commit time — prefer committed, it is 20 lines and it documents the starting point).
4. Note the built bundle size: `du -sh client/dist/assets`.
5. Create the working branch off `rework/2026`:
   ```bash
   git checkout -b fix/audit-remediation
   ```

Report it and continue — a broken baseline is information, not a blocker.
