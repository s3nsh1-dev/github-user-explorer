## Why

`useFetchUserData` and `useFetchRepositories` fetch the **identical URL**
(`https://api.github.com/users/:login`). The second exists only to read
`public_repos` — a field already present in the first hook's payload. Every
profile visit costs two identical network requests against a rate-limited API.

**P06** already gave them the same query key, so React Query is deduping them
right now. This plan removes the redundant code path.

## Steps

1. Confirm the dedupe is actually working: load `/user/torvalds?tab=repositories`,
   Network tab → **one** `/users/torvalds` request. If two, P06 was incomplete —
   stop and fix that first.
2. In [`Repositories.tsx`](../../client/src/page/Repositories.tsx), swap
   `useFetchRepositories(username)` for `useFetchUserData({ username })` and read
   `data?.public_repos`.
3. `git rm client/src/hooks/useFetchRepositories.ts`.
4. `grep -rn "useFetchRepositories" client/src` → must be empty.
