## Why

[`ShowSelectedRepo.tsx`](../../client/src/page/ShowSelectedRepo.tsx) is the only
file that opens `target="_blank"` without `rel`. Three other files already do it
correctly, so this is an inconsistency as much as a security nit. Cheapest
possible first commit.

## Steps

Edit [`client/src/page/ShowSelectedRepo.tsx`](../../client/src/page/ShowSelectedRepo.tsx),
adding `rel="noopener noreferrer"` immediately after each `target="_blank"`:

1. Line ~136 — Forks `<Chip component="a" href={`${html_url}/network/members`}>`
2. Line ~150 — Issues `<Chip component="a" href={`${html_url}/issues`}>`
3. Line ~173 — "Visit on GitHub" `<Button href={html_url}>`

That is the entire change. Three attributes.
