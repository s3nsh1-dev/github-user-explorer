## Why

Every `IconButton` in the app renders an icon and nothing else, so its
accessible name is empty. A screen reader announces "button" with no indication
of what it does — for all four pagination arrows, the star toggle, the back
button, and the starred-users dropdown.

## Steps

### 1. `aria-label` on every icon-only button

| File | Control | Label |
|---|---|---|
| `Pagination.tsx:68-88` | first / prev / next / last | `"Go to first page"`, `"Previous page"`, `"Next page"`, `"Go to last page"` |
| `UserProfileHeader.tsx:49` | star toggle | dynamic — see below |
| `ShowSelectedRepo.tsx:76` | back | `"Go back"` |
| `StaredRepositories.tsx:41` | dropdown | `"Starred profiles"` |

The star button also needs state, not just a name:

```tsx
<IconButton
  aria-label={isStarred ? `Unstar ${username}` : `Star ${username}`}
  aria-pressed={isStarred}
  onClick={...}
>
```

`aria-pressed` is what communicates toggle state; the icon swap alone is
invisible to a screen reader.

### 2. `aria-current="page"` on the active page button

[`PageButton.tsx`](../../client/src/components/PageButton.tsx) renders its
number as text, so it has a name — but the *active* page is signalled by colour
alone. Add `aria-current={active ? "page" : undefined}`.

### 3. Distinct `alt` text for avatars

[`UserCards.tsx:32`](../../client/src/components/UserCards.tsx#L32) uses
`alt="User-Profile-Picture"` for every card — a screen reader reads the same
string 20 times down the results list. Use `alt={`${userName}'s avatar`}`.
(`UserProfileHeader.tsx:43` already does this correctly — leave it.)

### 4. `<main>` landmark

The app has no landmark at all — everything renders into `<div id="root">` with
an `AppBar` on top. In [`App.tsx`](../../client/src/App.tsx), wrap `<Routes>`:

```tsx
<Box component="main">
  <Routes>…</Routes>
</Box>
```

### 5. Visible focus ring on the diamond page buttons

`PageButton` uses `clipPath: "polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%)"`,
which **clips its own focus ring** — the button is keyboard-focusable but the
focus is invisible. Add an explicit indicator that survives the clip, e.g. an
inset `box-shadow` on `&:focus-visible` rather than an `outline`.
